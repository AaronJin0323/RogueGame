Build: `da37a86` (before), then the commit that applies D-045 (job 1, its parent is `da37a86`). Each row's run file carries its own stamp in `run_start.build`.

## Method
`& Tools\BotRuns.ps1 -Arms None,Steered:Storm:Tempest,Steered:Storm:ArcGrid,Steered:Storm:Downpour -FirstSeed 9107 -Seeds 1`, one process at a time, skill 1.0, policy All, the Development editor build of each tree. Outcome, end, steps and `input_hash` are the bot record's (`bot.csv.txt`). HP lost is the sum of `hero_damaged` amounts over max HP for the whole run (`Tools/owner_read.py`'s definition), with the hit count. Rusher hits are `hero_damaged` records whose `role` is Rusher. The first difference is the first JSONL record that differs from the table before, `wall` fields and the build stamp left out.

- Drop-ins start with the timeline row at 270 s (`09_Catalog/timeline_arena1.csv`), one every 12 s and 70 % of them Rushers. The before runs count 45 (None), 82 (Tempest), 83 (ArcGrid) and 80 (Downpour) drop-ins in their `dir_block` records, so every arm meets Rusher arrivals from about 282 s on.
- An arrival's band is now 1200 to 1400 uu long, not 975, and passes through the hero. The bot steers out of telegraphs (`DTBotBrain`), so its path changes at the first arrival whose longer band reaches it, and `input_hash` covers its inputs.
- No arm differs before 270 s: the first differing record is at 283.8 to 320.0 s on the four arms, after the first drop-in landed. A difference before 270 s would have been a finding; there is none.
- An arm that did not move would also have been a finding, since all four meet arrivals. All four moved.
