# S4 frames: a staged scene at the real density

`Tools/Frames.ps1` shoots any scene of `Tools/Scenes` at a size you name into a folder you name, so the owner and the reviewers look at frames at the density art is judged at, not at the gate's. It launches the game as `Tools/Smoke.ps1` and `Tools/EnemyArt.ps1` do (hidden desktop, `-ForceRes`, the sim held on the shot step, the GPU semaphore held) and reads the scene file as `Smoke.ps1 -Scene` does, with `-ExtraCmds` appended and `-Seconds` to move the shot. The frame keeps today's framing (`C.ARENA.CAMERA_FRAME_RADIUS_UU`) and only its height in pixels changes: 1280x720 is the gate's size (24 px/m), 1920x1080 is 36 px/m, the density art is judged at (the default), and 1440x810 is 27 px/m, where it must still read (`C.EAR.SILHOUETTE_PX_PER_M`). Example: `& Tools\Frames.ps1 -Scene combat_staged -Culture zh-Hans -Width 1440 -Height 810 -Tag look27` writes `Saved\Frames\combat_staged_zh-Hans_1440x810_look27.png`. It judges nothing about the picture: no golden, no contrast, no text or key label check, never `-Update`. `FRAMES: PASS` says only that the run started, logged no crash, ensure or `LogDT` error, stayed inside the processor mask, and wrote a PNG of exactly the size asked; whether the frame is right is for the person looking at it.
