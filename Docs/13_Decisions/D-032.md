# D-032 — A gated Patron hand draws its last seat over every Keeper not yet seated

- **Date:** 2026-11-09
- **Decider:** scheduler (delegated, D-009)
- **Class:** RULE
- **Status:** applied

## Context
`dev/s3-earned-path` named this for a D-number at integration (`Validation/S3_earned.md`, "The hand, decided"). At `5ccf82e` the Patron hand of a gated run, Restart's included, read the last Patron, then Path order. A met Keeper not played last could never reach that hand, `Shade Storm Forge` dropped Tide for every run on a met lead, and `Storm Forge Tide` held no met Keeper at all. The doors (`S3_doors.md`) open Keepers the hand could then never show.

## Options
- A — a seat for each met Keeper: the first pass of `dev/s3-doors`, which its review removed; it reads `Shade Radiance Quicksilver` and shuts S1 Keepers out.
- B — a fourth seat: raises `C.OFFER.KEEPER_CHOICES` for a save, a number meta moves (D-023).
- C — the last seat drawn: one seat, the same plain draw as the L8 hand, with no Favor to weigh it.

## Decision
C. In a gated run with more Keepers than `C.OFFER.KEEPER_CHOICES`, the lead keeps the first seat, Path order fills the seats between, and the last seat is an unweighted draw over every Keeper not yet seated. A run with no met Keeper draws nothing, so a first run and any tool run on the full pool read as before. A Keeper `-DTUnlock` adds to a gated pool counts as met. Rule text: `keepers.md` R-KEE-23, `offers.md` R-OFF-08.

## Hypothesis
We believe a drawn last seat moves a met Keeper's reach of a Patron hand from "only when played last" to every Keeper of the run, because Path order never reached past Tide; measured at the external S3 session on a fresh and a full profile; reverted if a person reads the drawn seat as noise or misses an S1 Keeper it drew past.
