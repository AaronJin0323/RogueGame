# D-011 — RTX 4080 as the measurement proxy for the 4070 budget

- **Date:** 2026-10-30
- **Decider:** scheduler (delegated, D-009)
- **Class:** RULE
- **Status:** applied

## Context
`C.BUDGET.GPU_MS_4070` names a 4070-class GPU; the only measurement machine has an RTX 4080. `Harness/H07 §5` allows an agreed proxy factor written in `07_Technical` when the real device is not available. First stress measurement (`Tools/Perf.ps1`, 1920×1080, median load 5 975 bullets / 388 enemies): GPU p50 2.97 ms, p95 3.33 ms.

## Options
- A — buy or borrow a 4070 before S0 exits
- B — a pessimistic proxy factor: judge `GPU p95 × C.PERF.GPU_PROXY_4080_TO_4070` against the budget
- C — ignore the difference

## Decision
B, with factor 1.6. Public raster benchmarks put a 4070 at roughly 1/1.3–1/1.5 of a 4080; 1.6 deliberately overstates the gap. Proxied GPU p95 = 3.33 × 1.6 ≈ 5.3 ms against 12 ms. The game-thread budget is CPU-bound and does not use the factor. A real 4070 (and a 3060-class card for the lower tier) is measured before S4 exits, where the per-tier budgets are certified.

## Hypothesis
We believe the proxied GPU number is an upper bound on a real 4070; checked when a 4070 measurement exists (S4). If the real reading exceeds the proxied one, the factor rises and every GPU verdict since this decision is re-run.

## Impact
- New constant `C.PERF.GPU_PROXY_4080_TO_4070` = 1.6 (GATED(S4))
- `07_Technical §5` names the proxy; `Tools/Perf.ps1` applies it when the GPU name contains "4080"
