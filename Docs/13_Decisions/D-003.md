## Context

## Decision
- Engine UE 5.8.x (Windows install `E:\UE5\UE_5.8`, 5.8.3).

- macOS performance target hardware: M2 MacBook Air. Its frame budget is measured on the empty S0 arena and then set in `08_Constants.md §2` (GATED(S0)).
