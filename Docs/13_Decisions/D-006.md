# D-006 — GitHub (public) as origin and LFS host

- **Date:** 2026-10-28
- **Decider:** owner
- **Class:** GO-NOGO
- **Status:** applied

## Context
OPEN O-007. The Mac's SSH bare repo cannot hold Git LFS objects. The owner named `AaronJin0323/RogueGame` (empty at push time). It is **public**; the owner chose to keep it public after being told this publishes the whole tree, including `Handoff_Dusktracer/`.

## Decision
- `origin` = `https://github.com/AaronJin0323/RogueGame.git` (PC pushes over HTTPS through the signed-in GitHub CLI; the PC has no GitHub SSH key).
- The Mac checkout `~/Dev/Dusktracer` keeps the SSH bare repo as `origin` for gate commits and fetches LFS from GitHub (`lfs.url`), anonymously, because the repo is public.
- `Tools/MacGate.sh` uploads the commit's LFS objects to GitHub before the Mac checks it out.

## Impact
- Everything committed is public: never commit keys, tokens, or licence-restricted assets (`09_Catalog/licenses.csv` decides what may be committed).
- GitHub's free LFS storage and bandwidth are small; expect a data pack once art lands (S4).
- If the repo is made private later, the Mac needs GitHub credentials for LFS.
