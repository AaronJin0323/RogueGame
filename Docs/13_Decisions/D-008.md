# D-008 — Palette confirmed, with darker ground references

- **Date:** 2026-10-28
- **Decider:** owner ("Approve with fix")
- **Class:** RULE
- **Status:** applied

## Context
`04_Presentation §3` had eight values proposed for this project. Checked as flat sRGB luminance (WCAG): `Pal.Hero.Armour` #D9DDE2 against `Pal.Ground.Bright` #A39D92 was 2.0:1, below `C.PRE.CONTRAST_MIN`. The armour is lit, not emissive, so lighting scales it and the ground together and the flat ratio holds in the rendered frame. #A39D92 (Y 0.34) also broke the art book's lit-stone limit (Y ≤ 0.20).

## Decision
- `Pal.Ground.Bright` #A39D92 → **#7E7970** (Y 0.19): armour 3.2:1, player core 4.0:1.
- `Pal.Ground.Lit` #77736B → **#66625B** (Y 0.12), so it stays distinct from the bright reference.
- The other six proposed values are confirmed unchanged: `Pal.Player.TrailNeutral`, `Pal.Hero.Armour`, `Pal.Ground.Shadow`, `Pal.Rarity.Common`, `Pal.Rarity.Rare`, `Pal.UI.Panel`.

## Hypothesis
We believe the darker ground references let every non-emissive gameplay element meet `C.PRE.CONTRAST_MIN` in both weathers; measured by T-PRE-05 (smoke contrast step) on the S0 stress arena; revisit the ground tones, not the rule, if it fails.

## Impact
- `04_Presentation §3` rows above; `R-PRE-05` unchanged
- Not yet verified: the emissive enemy-side colours (telegraph, enemy round, optic) read 1.3–1.4:1 as flat swatches on the lighter grounds; only the rendered check (T-PRE-05) decides them
