# D-023 — The Tree keeps pool and utility nodes only; the old stat ranks are cut

- **Date:** 2026-10-31
- **Decider:** scheduler (delegated, D-009; D-022 told the spec to flag this)
- **Class:** RULE
- **Status:** applied

## Context
Blueprint pillar 5 and D-022: meta widens the card pool and does not raise numbers. The old trunk (`01_GameDesign.md §8.2`) grants stat ranks: +Max HP, Armor, +XP gain, +Pickup radius, Starting weapon L2, +Luck. Each branch also grants +1 Favor, Ultimate cooldown −20% and a free blessing at run start. All of them raise in-run power, and non-negotiable 1 (threats are skill checks) has no room for a permanent power curve: the S1 and S2 bands are read at Heat 0 with no meta.

## Options
- A — Keep the source's tree. Runs grow easier with play; every band read so far stops holding once a profile has ranks, and D-022 would keep all of it off `dev/s2` and `main`.
- B — Keep pool and utility nodes only: Reroll, Banish and Lock from the trunk; the blessing and Fusion unlocks from each branch. Cut the rest.
- C — Keep the stat ranks at small values. Still a number; the same conflict, smaller.

## Decision
B. No Tree node may raise a number in a run: not a `FDTStatSet` value, a Favor count, a cooldown, a level or a starting rank. `meta.md` R-MET-20 lists every source node with its class and call. Luck is held rather than cut, because `offers.md` names it as a meta item; it is not built until a human reading says it stays.

## Hypothesis
We believe a Tree of unlocks and offer tools keeps the bands read at Heat 0 true for every profile, because no node touches a run's numbers, while the pool growing still gives runs a reason to feed the next. Measured when the Tree exists: T-MET-20, then the external S3 session asking whether spending felt worth it. Revisited if that session reads no pull from the Tree.

## Impact (dependency sweep)
- Rules: `meta.md` R-MET-20 (new); nothing replaced in code, the Tree does not exist yet.
- Constants: none. The source's rank costs are not carried.
- Files / tests / text prefixes: `Docs/02_Systems/meta.md`; T-MET-20 PLANNED with the Tree; the source's `ST_Tree` rows for the cut nodes are never imported.
- Retires / merges with: the source's trunk stats and branch stats; +XP gain and +Pickup radius count as stats here, though they read as utility, because both are XP rate.

## Swap-out point (if temporary)
The external S3 session, if the Tree reads as nothing to want. A change there is a new decision, and a node that raises a number stays off `dev/s2` and `main` under D-022.
