# D-084 — Short texts take a display face of the game's own; all capitals only for a message that is important, short and neat

- **Date:** 2026-11-13
- **Decider:** the owner, in words and one picture (2026-11-13); the scheduler for scope, source and order (delegated, D-009)
- **Class:** RULE (`02_Systems/hud.md` R-HUD-08's type table and a rule of capitals to be written; `04_Presentation` R-PRE-10 for the font's source). It replaces the display half of the first visual wave's package G (`Validation/S4_wave1.md` on `dev/s4`)
- **Status:** accepted; designed and built by the Visual session on `dev/s4`

## Context
- Every text of the game is drawn on the engine's font. Fonts were the last package of the first visual wave (G: two families as OFL files from outside the repo) and were held: the Canvas path for a font that is not the engine's is unproved, and outside files on the public repo are the owner's ground (D-006).
- The owner's word of 2026-11-13, typed to the scheduler with a picture: "give this to Visual session, use this style of fonts in short texts, all upper cases should only be used in important, short, neat messages, other messages should not use all upper case".
- The picture is an alphabet of capitals in a very heavy, tightly condensed poster grotesque: tall narrow letters, round letters built as rounded rectangles, counters cut as narrow slots, a small spur at the top left of most stems. It reads as cut or stamped lettering. Its source and licence are unknown; it is kept outside the repository, as the art direction is.
- How many texts are all capitals today has not been counted.

## Options
- **A.** Fetch an OFL face near the picture's style (package G's road).
- **B.** Draw the game's own display face by a script in the repo, in the picture's spirit.
- **C.** Keep the engine's font and change only the capitals.

## Decision
B, with the owner's rule of capitals.

1. **A display face for short texts.** Titles, banners, names, headings, labels, buttons, and numbers where they read, are set in one heavy condensed display face. Reading text (descriptions, help lines, Codex bodies, Keeper lines) keeps a reading face, today the engine's. The Visual session draws the line between the two with a list of every text place in the game.
2. **The picture is direction and is not copied** (D-077). Its outlines are not traced and it never enters the repository. The Visual session designs the game's own face in its spirit and aims past it.
3. **The face is generated by a script in the repo** (R-PRE-10: procedural, licence own): capitals, lower case, digits and the punctuation the string tables use. The font file is written by a tool of the repo with the standard library only. No outside font file is fetched for it and nothing is installed. Every other asset of the look is made this way; a face of our own can be cut for this world and for the HUD's sizes; and an outside file stays the owner's step.
4. **If the own face cannot hold** (the engine does not take the written file, or the drawn face does not read at the HUD's sizes), the Visual session names one OFL face and the outside file goes to the owner as their step.
5. **The rule of capitals.** All capitals only for a message that is important, short and neat: an event or a result, of a few words, on one line. Every other text is not all capitals: labels, names, buttons, headings and descriptions are written in mixed case. The Visual session drafts the rule's sentence and its bound, with an audit of every string that is all capitals today and every place the code upper-cases a text, each marked keep or change, and a lint in `Tools` that fails an all-capitals string outside the allowed list.
6. **Chinese** has no case and no glyph in this face: zh-Hans short texts keep their present face, and the type sheet says how a zh short text carries the same weight. A CJK display face is not opened by this record.
7. **Where and when.** `dev/s4` only; the first stage's build on `main`, which session A is measured on, keeps its text. The first half needs no engine and starts at once: the type sheet (the alphabet; mock frames of the game's real places at 1920x1080 in en, one in zh-Hans), the audit, and the proof on a hidden desktop that Canvas draws and measures a font that is not the engine's. The build half (the type table, every width moves, every HUD and screen golden shot again) lands after the camera has reached `dev/s4`.
8. **Acceptance** is by eye on the game's frames at real size, the scheduler's and then the owner's (D-077); the lint and the layout tests are guards.

## Hypothesis
We believe that short texts in one heavy condensed face of the game's own, with capitals kept for the few messages that matter, make the screen read faster and look made rather than assembled, because weight then marks what is short and capitals mark what is important, instead of both marking everything; judged on the game's frames at real size by the scheduler and by the owner's eye; reverted to the engine's face if the drawn face does not read at the HUD's sizes.
