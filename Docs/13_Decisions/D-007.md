# D-007 — macOS deferred; Windows only for now

- **Date:** 2026-10-28
- **Decider:** owner ("we can leave macos a little behind. Let's go for Windows only right now.")
- **Class:** VALVE
- **Status:** applied

## Context
D-003 made macOS a parallel platform. The Mac is reachable (`dt-mac`) but has no Xcode or UE 5.8, so its gate could only report `not run`.

## Decision
Win64 is the only platform in the merge gates until this valve is reopened. macOS stays a target: code keeps compiling-clean habits (no Windows-only APIs outside `#if PLATFORM_WINDOWS`), `Mac` stays in `TargetPlatforms`, and `Tools/MacGate.sh` and the Mac setup are kept, but not run.

## Swap-out point
Reopen when Xcode and UE 5.8 are installed on the Mac, and in any case before S3 (first full package). Reopening restores D-003's Mac gate and the `C.BUDGET.MAC_*` measurement.

## Impact
- Replaces the parallel-platform clause of D-003 until reopened
- `11_Quality §1`: Mac gate removed from the merge list
- `C.BUDGET.MAC_*` stay GATED and do not count toward `C.GATED.DEBT_MAX` while deferred
