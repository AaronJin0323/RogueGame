# D-015 — Starting weapon; Keeper-caused reshaping is Keeper damage

- **Date:** 2026-10-30
- **Decider:** scheduler (delegated, D-009)
- **Class:** RULE
- **Status:** applied

## Context
1. No spec gave the starting loadout: after the Patron pick the hero owned no weapon and could not fight until the first level-up.
2. `weapons.md` R-WPN-07 kept `Weapon.<Name>` as the telemetry source of reshaped rounds (conversion), while `keepers.md` R-KEE-13 says Keeper cleaves carry `Keeper.<Path>`. The S1 exit criterion "Keeper share ≥ `C.POWER.KEEPER_SHARE_L16`" is read from these sources (`Tools/power_split.py`), so the conflict biases the core measurement.

## Decision
1. Every player starts the run owning `Weapon.PulseRifle` at its first level, granted right after the Patron pick (`offers.md` R-OFF-08). The Pulse Rifle is the baseline aimed projectile and a natural fit for all three S1 Keepers; the start is not a decision.
2. Reshaping caused by a Keeper flag carries `Keeper.<Path>`; reshaping caused by a modifier or the weapon itself keeps `Weapon.<Name>` (`weapons.md` R-WPN-07 amended).

## Hypothesis
1. A validator is fighting from the first second; first-minute death rate without input stays a director concern, not a loadout one.
2. The source split then matches the ablation measure of Keeper power within `C.POWER.ARCHETYPE_BAND`; checked when bot v1 runs ablations.

## Impact
`offers.md` R-OFF-08, `weapons.md` R-WPN-07; code in the keepers package (flag source tagging) and the run-start hook.
