# D-025 — Every human launch draws a fresh seed; tools and named seeds stay exact

- **Date:** 2026-11-01
- **Decider:** scheduler (delegated, D-009)
- **Class:** RULE
- **Status:** applied

## Context
`Play_*.bat` joined two `%RANDOM%` values into a number that often overflows `int32`, and `FParse::Value` saturates, so about 24 percent of launches ran on `2147483647`, and about 69.5 percent did inside a 57.6 minute window every 167 minutes. `Tools\Play.bat` and a bare exe passed nothing and ran on seed `0` every time. No rule covered either path, and `PadCheck` matched a fragment of the launcher's text, so the gate could see neither fault. Evidence: the owner's run `2147483647_20261031_231306`, build `996cd47`, one designer run, not a validator session (`Validation/S1_human_seed.md`).

## Decision
`07_Technical` R-TEC-16, one source for a run's seed, `FDTRunSeed`:
- The game draws the seed, not the launcher, so `Tools\Play.bat`, the package and a bare exe share one path. It replaces `-DTSeed=%RANDOM%%RANDOM%` and the saturating read; both are gone.
- A tool is `FApp::IsUnattended()`: `-unattended` or an automation test. A tool with no seed stays on `0`, the seed the goldens and perf scenes are read on.
- A fresh seed is `1` to `2147483646`. `2147483647` is never drawn, so in a run file's name it means a replay or the old launcher, and it stays a valid seed so the owner's run can be replayed.
- A `-DTSeed` that is not a whole `int32` is rejected, never saturated or wrapped: exit code `2`, no run, no run file. Play in the editor stays open.

## Result
`input_hash` on seed 9107 is unchanged on 10 of 10 arms and lengths, against `996cd47`. Gate step `seed` (`Tools/SeedCheck.ps1`) fails on the old launcher line and on a game that defaults a human to `0`. No balance number moved.

## Impact
- `DTRunSeed.*`, `UDTSimSubsystem::GetLaunchSeed`, `DTGameMode`, the launchers, `Tools/SeedCheck.ps1`, gate step `seed`; R-TEC-16, T-TEC-16, R-PKG-04, T-PKG-04.
- Not verified: a person double-clicking a launcher in full screen, and Play in the editor's redraw and reject (`Validation/S1_human_seed.md`, Not verified).
