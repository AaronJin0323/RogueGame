# D-027 — A free volley stays its modifier's under a Keeper conversion; a silenced socket shows

- **Date:** 2026-11-01
- **Decider:** scheduler (delegated, D-009)
- **Class:** RULE
- **Status:** applied

## Context
Two faults in one reading of the owner's run (designer run, build `996cd47`, not a validator session; `Validation/S1_modifier_truth.md`). A Keeper conversion read as `Keeper.<Path>` also relabelled Chain Trigger's free volley, so a modifier's own damage was counted as Keeper damage. And a blessing that silences a socket said so nowhere: the socket simply stopped working.

## Decision
1. D-015 stands and is bounded: it covers reshaping the weapon's own rounds. A modifier's free volley or copy is an extra emission and stays `Modifier.<Name>` (R-WPN-07, R-KEE-13).
2. A dormant socket shows (R-MOD-08). The card reads the composition, never the card's flags or the round count, so it names whatever the composition silences, also on a weapon that keeps a round flying.
3. Only a blessing can silence a socket. An Intercession's overlay is left out of the card, because it passes and moves no socket.
4. R-OFF-11 (b) binds level-up hands. A chest hand has no guaranteed slot (R-OFF-14). The code stays; the sentence is narrowed, and T-OFF-11 pins it.
